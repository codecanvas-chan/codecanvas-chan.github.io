# CodeCanvas - 프로젝트 포트폴리오

## 회사 소개
CodeCanvas는 임베디드 시스템, 모바일 애플리케이션, 하드웨어 제어 솔루션을 전문으로 하는 기술 개발 회사입니다. FPGA 설계부터 안드로이드 앱 개발, QT 기반 GUI 개발까지 다양한 영역에서 프로젝트를 수행하고 있습니다.

---

## 핵심 역량

### 임베디드 시스템
- FPGA 설계 및 구현 (Xilinx Zynq)
- ARM 기반 SoC 개발 (i.MX8, ESP32)
- 리눅스 커널 및 Yocto 빌드 시스템
- 실시간 신호 처리

### 소프트웨어 개발
- **언어**: C/C++, C#, Verilog/VHDL
- **프레임워크**: QT/QML, GStreamer
- **모바일**: Android Native/Java
- **통신**: TCP/IP, UART, LVDS, FTP, RTSP

### 품질 관리
- MISRA-C 코딩 표준
- 정적 분석
- Doxygen 문서화
- Git 버전 관리
