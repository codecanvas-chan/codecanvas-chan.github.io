How we work

투명하게 진행하고, 문서로 남깁니다

주 단위 진행 보고와 중간 빌드 배포로 진행 상황을 언제든 확인하실 수 있고, 납품 시 소스·바이너리·개발 문서를 함께 전달합니다.

  1. 요구사항 분석

    요구사양서와 하드웨어·인터페이스 조건을 검토하고 불명확한 부분을 질의로 정리합니다.

    요구사항 정의

  2. 설계 · 일정 산정

    시스템 구조와 통신 프로토콜을 설계하고 마일스톤별 공수를 산정합니다.

    설계서마일스톤

  3. 개발 · 주간 보고

    주 1회 진행 보고와 중간 빌드를 공유하고 Git으로 변경 이력을 관리합니다.

    주간 보고중간 빌드

  4. 검증 · 납품

    실장비에서 시험하고, 필요 시 MISRA 정적 분석과 Doxygen 문서화를 수행합니다.

    소스바이너리문서

  5. 검수 · 후속 지원

    검수 기간 이슈에 대응하고, 기능 개선은 후속 단계로 이어서 진행합니다.
