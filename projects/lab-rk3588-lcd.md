# Orange Pi 5 (RK3588) SPI LCD · 터치 드라이버 브링업

## 개요

RK3588 기반 주행 모델 포팅 작업에서 **차량 내 디스플레이**로 쓰려고, 3.5인치 SPI LCD(ILI9486)와 저항막 터치(XPT2046)를 Orange Pi 5에 브링업했습니다. 다른 보드용으로 만들어진 모듈이라 핀 매핑부터 새로 잡아야 했고, 브링업 도중 **터치 인터럽트가 발생하지 않는 문제**가 나왔습니다. 이 문제는 커널 드라이버를 직접 작성해 해결했습니다.

## 작업 내용

- **Device Tree 오버레이**: 26핀 헤더를 RK3588의 SPI4와 GPIO에 매핑하고, LCD(fbtft)와 터치 컨트롤러를 같은 SPI 버스에 서로 다른 CS로 등록했습니다.
- **폴링 터치 드라이버**: 터치 인터럽트(PENIRQ)가 보드에서 발생하지 않는 것을 확인했습니다. 그래서 인터럽트 대신 주기적으로 좌표를 읽는 **out-of-tree 커널 모듈(`ads7846_poll`, 527 lines)**을 작성했습니다.
- **보정 · 디버그 도구**: Qt 기반 터치 보정 앱과 좌표 시각화 도구를 만들어 정확도를 맞췄습니다.
- **성능 튜닝**: SPI 50 MHz에서 프레임버퍼 약 17.7 FPS까지 측정한 뒤, 차량 환경에서 안정적인 설정으로 확정했습니다. 전체 과정을 716줄 분량의 포팅 기록으로 남겼습니다.

## 기술 스택
