# 위성간 레이저 통신용 수신기 FPGA 개발

## 프로젝트 개요

위성 간 레이저 통신에서는 송신 레이저가 수신기 중심에 정확히 맞아 있어야 링크가 유지됩니다. 이 프로젝트는 **4분할 수광 센서(Quadrant Photodiode)** 신호를 고속으로 받아 필터링하고 상위 시스템에 실시간으로 전달하는 **수신기 신호처리 보드**를 Xilinx Zynq-7020 기반으로 개발한 것입니다.

4인 팀에서 **FPGA RTL 설계와 Zynq PS 펌웨어**를 맡았습니다. ADC 제어부터 디지털 필터, 프레임 생성, 직렬 송신까지 데이터 경로 전체를 PL(프로그래머블 로직)에 하드웨어로 구현했습니다. CPU는 상위 시스템이 보내는 제어 명령만 처리하므로 데이터 경로가 소프트웨어 지연의 영향을 받지 않습니다.

## 동작 원리

수광 센서는 네 개의 사분면(A·B·C·D)으로 나뉘어 있습니다. 레이저 스폿이 중심에 있으면 네 신호가 같고, 중심에서 벗어나면 그 방향의 신호가 커집니다. 네 채널을 **동시에** 샘플링해야 스폿 위치를 정확하게 계산할 수 있습니다.

```
      B | A            x̂ = ((A + D) − (B + C)) / (A + B + C + D)
     ---+---           ŷ = ((A + B) − (C + D)) / (A + B + C + D)
      C | D
```

보드는 필터링한 4채널 원시값을 고속 프레임으로 내보냅니다. 상위 시스템은 이 값으로 스폿 위치와 정렬 각도를 계산합니다.

## FPGA 구현 상세

### 1. AD7606C 컨트롤러

<figure class="fig"><div class="frame pad"><img src="assets/diagrams/satellite-adc-fsm.svg" alt="AD7606C 제어 FSM: 초기화 단계와 변환 루프"></div><figcaption><b>FIG 2</b><span>ADC 제어 FSM. 전원을 넣으면 레지스터 모드로 들어가 입력 범위와 대역폭을 설정한 뒤 변환 루프를 반복합니다. 루프 한 번에 5,018클럭(약 50.2 µs)이 걸리며, 이는 채널당 약 19.9 kS/s입니다.</span></figcaption></figure>

- 데이터시트의 전원 안정화(15 ms)와 리셋(4 µs, 300 µs) 시퀀스를 카운터로 정확히 구현했습니다.
- **소프트웨어(레지스터) 모드**로 들어가 장치 응답을 확인한 뒤, CH1–4를 ±10 V 차동 입력과 고대역 모드로 설정합니다.
- 변환할 때는 `CS`를 Low로 유지한 채 `RD`만 4번 스트로브해 병렬 버스로 4채널을 연속으로 읽습니다.

### 2. 디지털 저역통과 필터

- 1차 IIR 구조 `y[n] = (A·x[n] + B·y[n−1]) >> 16`를 Q16 고정소수점으로 구현했습니다.
- 곱셈, 덧셈, 시프트를 **3단 파이프라인**으로 나눠 100 MHz에서 타이밍을 맞췄고, DSP48 블록에 매핑됩니다.
- 채널마다 인스턴스 하나씩, 총 4개가 병렬로 동작합니다. 필터 모드(Off / 1 / 5 / 10 kHz 설계값)는 호스트 명령으로 실행 중에 바꿀 수 있습니다.

### 3. 프레임 생성과 직렬 송신

- **33바이트 상태 프레임**: 시작·종료 바이트, 길이, 상태, 버전, 4채널 16-bit 원시값, 동작 모드, XOR 체크섬으로 구성합니다.
- 1.51 µs마다 1바이트를 내보내 10 Mbps 링크에서 **초당 약 2만 프레임**을 보냅니다. 채널 샘플링 주기와 맞춘 값입니다.
- UART TX/RX를 직접 설계했습니다. RX 쪽에는 2단 플립플롭 동기화기와 비트 중앙 검출을 넣어 외부 신호를 안정적으로 받습니다.

### 4. PS 펌웨어 (Bare-metal)

- RX 바이트가 들어올 때마다 인터럽트(IRQ_F2P)로 깨어나 **17바이트 명령 프레임**을 조립하고, 시작·종료·길이를 검증합니다.
- 명령 파서는 AXI-GPIO 제어 레지스터를 통해 필터 모드, 아날로그 게인, 보정 모드, 기울기 계수, 송신 시작 신호를 PL에 전달합니다.

## 구현 결과

| 항목 | 결과 |
|------|------|
| 샘플링 | 4채널 동시, 채널당 약 19.9 kS/s |
| 출력 | 33 B 프레임, 약 19.9k frames/s @ 10 Mbps |
| 자원 사용 | LUT 1,482 (2.8%) · FF 1,648 (1.6%) · DSP48 12 (5.5%) · BRAM 0 |
| 타이밍 | 100 MHz 타이밍 충족 (WNS +2.33 ns) |
| 코드 규모 | Verilog RTL 5개 모듈 (~1.1k lines) + 테스트벤치, PS C 6개 파일 |

개발 보드(Arty Z7-20)에서 ADC·필터·UART를 먼저 검증하고 최종 타깃 보드로 옮겨 실제 레이저 센서로 동작을 확인한 뒤 납품했습니다. 자원 사용률이 낮아 앞으로 필터 차수를 늘리거나 채널을 추가할 여유가 충분합니다.

## 프로젝트 의의

레이저 위성 통신은 RF 통신보다 대역폭이 크고 보안성이 높아 차세대 위성 간 링크 기술로 주목받고 있습니다. 이 프로젝트에서는 링크 정렬의 출발점인 **수광 신호 획득 경로**를 지연이 일정한 하드웨어 파이프라인으로 구현했습니다. 정밀 ADC 제어, 고정소수점 DSP, 커스텀 직렬 링크를 데이터시트 수준에서 설계·검증한 사례입니다.
