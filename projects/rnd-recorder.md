# 차량 ADAS 보드 영상 · 인식 결과 레코더

## 개요

차량용 ADAS 보드를 실차에서 검증할 때는 카메라 영상만으로는 부족하고, **보드가 그 순간 무엇을 인식했고 어떤 차량 신호를 받았는지**를 함께 봐야 합니다. 이 도구는 보드가 내보내는 카메라 스트림, 인식 결과, CAN 신호를 **프레임 단위로 묶어 녹화**하고, 브라우저에서 실시간으로 보거나 주행 전체를 재생·검색·분석할 수 있게 해 줍니다.

Python 서버와 브라우저만 있으면 Windows와 Linux에서 바로 실행됩니다. 3D BEV(Bird's-Eye View), 주행 전체 타임라인, 조건 검색, 그래프, 북마크, 클립, 스냅샷까지 검증 엔지니어가 매일 쓰는 기능을 하나의 화면에 모았습니다.

## 시스템 구조

<figure class="fig"><div class="frame pad"><img src="assets/diagrams/recorder-architecture.svg" alt="레코더 시스템 구조: 보드, PC 서버, 브라우저"></div><figcaption><b>FIG 1</b><span>시스템 구조. 보드는 카메라와 CAN 입력에 자체 클럭으로 타임스탬프를 찍어 프레임마다 SEI에 담아 보냅니다. PC는 스트림을 그대로 녹화하고, 필요한 파일을 분리하고, 브라우저에 화면과 결과를 전달합니다.</span></figcaption></figure>

- **녹화**: 수신한 스트림을 손대지 않고 저장합니다. PC는 타임스탬프를 새로 찍지 않고 보드 타임스탬프를 그대로 쓰므로, 영상과 CAN 신호 사이의 시간 관계가 보드에서와 똑같이 보존됩니다.
- **파일 분리**: 녹화본에서 CAN csv(Resim 입력), 프레임별 신호·결과 바이너리, 프레임 인덱스를 뽑아냅니다. 파일이 없어져도 녹화본에서 다시 만들 수 있습니다.
- **화면 전달**: 프레임은 GPU로 디코딩(Windows d3d11va, Linux vaapi)하고, 페이지가 보여주는 크기로 **한 번만 JPEG 인코딩해 모든 페이지가 공유**합니다. 결과는 WebSocket으로 전달합니다.

## 기술 포인트

- **빌드별 데이터 구조 자동 대응**: 보드 소프트웨어 빌드마다 결과 구조체의 크기와 필드가 다릅니다. 그래서 빌드 산출물의 디버그 정보(ELF/DWARF)에서 **구조체 레이아웃을 자동 추출**해 JSON으로 저장하고, 수신한 데이터 크기로 맞는 레이아웃을 골라 읽습니다. 일부 필드가 없는 빌드에서도 나머지 결과는 정상적으로 표시됩니다.
- **보드 화면 재현**: 보드가 그리는 결과 오버레이 로직을 Python으로 포팅해, PC에서 보드 화면과 같은 표시를 재현합니다.
- **테스트 용이성**: 가상 주행 녹화를 만드는 시뮬레이터와 단위 테스트 62개로, 보드 없이도 녹화·분리·재생 경로를 검증합니다.
- **배포 단순화**: 설치 요구 사항은 Python과 Chrome/Edge뿐입니다. 버전이 다른 페이지가 열려 있으면 새로고침하도록 안내합니다.
