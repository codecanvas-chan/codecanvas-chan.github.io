# ADAS 인지 연구 — 소실점 캘리브레이션 · 차선 검출

## 개요

주행 보조 시스템의 카메라 인지 부분을 직접 학습하고 개선한 연구입니다. 카메라 자세를 자동으로 보정하는 **CNN 소실점 검출**을 논문 재현으로 구현했고, 차선 검출 모델(LaneAF)을 자체 출력 구조로 개조했습니다.

## CNN 소실점 기반 카메라 자동 캘리브레이션

- 소실점을 CNN으로 검출해 카메라 자세를 추정하는 공개 논문(ICCP 2017)을 PyTorch로 재현했습니다.
- CULane 차선 라벨에서 **소실점 학습 라벨 15,905개를 자동으로 만들었고**, 검증 RMSE 최저 3.40(정규화 거리 0.022)을 얻었습니다.
- 검출한 소실점을 카메라 **pitch / yaw 각도로 변환**해 장착 오차를 자동 보정하는 데 씁니다.

## 차선 검출 모델 개조 (LaneAF)

- 빌드가 까다로운 DCNv2 의존성을 없애고 Apple Silicon(MPS) 학습을 지원하도록 바꿨습니다.
- 주행에 필요한 **Ego lane 기준 차선 3개(ego-triplet)**를 바로 출력하는 TuSimple 기반 구조를 설계했습니다.
- 검증 lane F1: DLA-34 백본 **0.918**, ERFNet 0.878

## 기술 스택

PyTorch · Apple MPS · CULane · TuSimple · OpenCV · DLA-34 / ERFNet
